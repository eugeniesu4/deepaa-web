# DeepAA Web

A browser front-end based on the original DeepAA on Web implementation.

Original project: https://github.com/OsciiArt/DeepAA
Web implementation reference: https://github.com/n317/DeepAAonWeb

## Usage

Open the GitHub Pages site, choose an image, adjust Output Width, then press Start. Processing is performed in the browser using the DeepAA Web model assets.
