# DeepAA Web

Personal GitHub Pages deployment based on the original DeepAA on Web implementation.

- Original DeepAA: https://github.com/OsciiArt/DeepAA
- Web implementation reference: https://github.com/n317/DeepAAonWeb
- Live site: https://eugeniesu4.github.io/deepaa-web/

## Usage

1. Open the live site.
2. Choose an image.
3. Set **Output Width** (try 80–150 for a useful starting point).
4. Press **update**.
5. Press **Start** and wait for the model to finish.
6. Use **Copy to clipboard** to copy the generated AA.

The original DeepAA Web model runs in the browser. The large model asset is proxied from the original public Web implementation rather than re-hosted in this repository because GitHub's text-file connector cannot upload binary model blobs directly.
